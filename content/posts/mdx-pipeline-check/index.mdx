This post exists to prove one thing: a file in `content/posts/` reaches its route,
with its frontmatter validated on the way. It is a draft, so it is never
prerendered and never enters the sitemap, and T-20 deletes it once the eleven
real posts are imported.

## What it exercises

- `gray-matter` splits the frontmatter from the body.
- The Zod schema closes `category` on the three D-09 values, so a typo fails the
  build with the file and field named.
- `/posts/[slug]` prefers a local post over Cosmic, which is the bridge T-20
  crosses for real.

## What highlighting looks like

Shiki runs at build time, so the colours below are in the server HTML and cost
no client JavaScript:

```tsx
export const postMetadata = ({ title, canonical }: PostMeta): Metadata => ({
  title,
  alternates: { canonical },
})
```

```bash
bun run validate:content
```
